# AutoVJ

AutoVJは、入力された音声から曲を判定し、その曲に対応する動画をブラウザ上で自動再生するWindows向けオートVJソフトです。

LINE入力などの録音デバイスのほか、PCで再生中の音声を取り込むWASAPIループバック入力にも対応しています。曲のテンポに合わせて動画の再生速度と位置を補正し、曲が切り替わると映像も自動的に切り替えます。

## このソフトが適している人

- VJがいないDJイベントで、楽曲に対応した映像を自動再生したい人
- DJプレイに集中し、映像操作をAutoVJへ任せたい人
- 手持ちの音源と動画の組み合わせを、PCだけで確認したい人

映像の完全な同期精度より、自動運転と手軽さを優先する用途に適しています。

## 動作環境

- Windows 11 64bit
- インターネット接続（初回セットアップ時）
- MP4を再生できるWebブラウザ
- LINE入力などの録音デバイス、またはWASAPIループバックを利用できる再生デバイス

初回セットアップスクリプトが、必要に応じて .NET 10 SDK、NuGetパッケージ、`ffmpeg`、`ffprobe` を自動的にダウンロードします。管理者権限やシステム全体のPATH変更は必要ありません。

## 自動セットアップ

GitHubからリポジトリを `git clone` したあと、プロジェクトフォルダ内の次のファイルをダブルクリックします。

```text
setup-and-run.cmd
```

## 動画素材の準備

自動セットアップによって作成されたフォルダへ、次のようにMP4を配置します。

```text
main-videos/
├─ 曲Aの動画.mp4
├─ 曲Bの動画.mp4
└─ 曲Cの動画.mp4

material-videos/
├─ common_movie.mp4
├─ glitch1.mp4
├─ glitch2.mp4
└─ glitch3.mp4
```

- `main-videos` には、曲を判定したときに再生するMP4を配置します。
- 判定に使う音声はMP4内の音声トラックです。別途MP3を用意する必要はありません。
- `common_movie.mp4` は、曲を検出していないときに再生する動画です。
- `glitch1.mp4`～`glitch3.mp4` は、検出信頼度が下がったときに重ねる演出素材です。
- ファイル名や素材フォルダは `config.yaml` で変更できます。

### 動画を解析する

`scan-videos.cmd` をダブルクリックします。

解析済みのMP4は、ファイルが更新されない限り再解析されません。動画を追加・更新・削除した場合は、同じコマンドをもう一度実行してください。

## 起動

初回セットアップ後は、`run-autovj.cmd` をダブルクリックして起動します。

起動すると既定ブラウザでウェルカムページが開き、設定済みの音声入力の監視が始まります。自動的に開かない場合は、次のURLへアクセスしてください。

```text
http://127.0.0.1:5180/
```

### 各ページの役割

- ウェルカムページ `/`
  - 再生ページと設定ページを別タブで開く入口です。
- 再生ページ `/output`
  - 映像だけを表示します。プロジェクター、別モニター、OBSのブラウザソースなどで使用します。
- 設定ページ `/setting`
  - 入力状態と検出状況を確認し、音声入力や再生設定を変更します。

### 設定ページで変更できる内容

- 録音入力とWASAPIループバックの選択
- 音声入力の一時停止と再開
- 入力デバイスごとの再生位置補正
- 曲を見失ってから共通動画へ戻るまでの時間
- 動画位置の再同期、再生倍率、BPM補正範囲
- クロスフェード時間とブレンド演出
- グリッチ演出のしきい値
- 登録済み動画の確認

設定を保存すると、`config.yaml` と実行中の再生ページへ反映されます。

再生位置補正はミリ秒単位です。正の値は動画を先へ進め、負の値は動画を遅らせます。設定値は選択中の入力デバイスへ個別に保存されます。

## 起動オプション

```text
--lan          LAN内のほかの端末からアクセスできるようにする
--port 5180    今回使用するポート番号を指定する
--pin 1234     今回使用する4桁のPINを指定する
--pin=         今回だけPIN認証を無効にする
```

オプションは次のように指定します。

```cmd
run-autovj.cmd --lan --port 5180 --pin 1234
```

## LAN公開とPIN

`--lan` を付けて起動すると、同じLAN内のPC、スマートフォン、タブレットからアクセスできます。

別端末では、AutoVJを起動しているPCのIPアドレスとポート番号を指定します。

```text
http://192.168.1.100:5180/
```

- PINは `config.yaml` の `server.lan_pin`、または起動時の `--pin` で指定します。
- **デフォルトのPINは"1111"です**。PINは4桁の数字、または無し（空欄）を設定できますが、**PIN無しのLAN公開は推奨しません**。
- 通常起動ではPINを要求しません。
- `--lan` 起動でもPINが空欄なら認証を行いません。
- PIN認証後の状態はブラウザを閉じるまで有効です。
- LAN公開はHTTP通信です。信頼できるローカルネットワーク内だけで使用してください。
- Windowsファイアウォールが通信を遮断した場合は、使用するポートへの受信接続を許可してください。

## `config.yaml` で設定できる内容

通常の操作は設定ページから行えます。起動前に変更する必要がある項目は `config.yaml` を編集します。

| セクション | 主な内容 |
| --- | --- |
| `server` | 待受アドレス、ポート、ブラウザ自動起動、LAN用PIN |
| `media` | 登録動画・共通動画・演出素材のフォルダとファイル名 |
| `audio` | 起動時に使用する入力デバイス、解析用サンプルレート |
| `audio_position_offsets` | 入力デバイスごとの再生位置補正 |
| `detection` | 検出間隔、信頼度、入力レベル、テンポ倍率 |
| `playback` | 未検出時の動作、再同期、再生倍率、BPM範囲 |
| `transition` | クロスフェードとブレンド演出 |
| `glitch` | グリッチ演出の有効化、しきい値、素材ファイル |
| `storage` | 解析データベースの保存場所 |
| `ffmpeg` | `ffmpeg` と `ffprobe` の実行パス |
